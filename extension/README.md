# QuestionPulse Teacher Copilot Extension

这是 V2-P0 的 Chromium Manifest V3 悬浮助手。教师悬浮界面只注入 `https://live.polyv.net/*`，通过教师令牌读取 QuestionPulse 教师快照，不读取摄像头、麦克风、浏览历史或 POLYV 登录信息。本地教师后台还加载一个无界面的配对脚本，用于教师主动点击“一键连接开播助手”时写入当前浏览器会话凭据。

## 本地加载

1. 打开 Edge 的 `edge://extensions`。
2. 开启“开发人员模式”。
3. 选择“加载解压缩的扩展”，目录选择本文件夹 `extension/`。
4. 源码更新后在扩展卡片上点击“重新加载”，再刷新已打开的 POLYV 页面。
5. 使用教师专属入口打开 QuestionPulse 教师后台，点击“连接开播助手”。
6. 返回或刷新 POLYV 网页开播台，点击右下角 QuestionPulse 脉搏球。

如果教师后台没有检测到扩展，仍可在悬浮助手中手工输入后端地址、课堂 ID 和教师访问令牌。

教师令牌只存储在当前浏览器会话的 `chrome.storage.session` 中，关闭浏览器后自动失效。
内容脚本不直接跨域请求后端；所有 API 调用经后台 Service Worker 转发，并受 manifest 中的本机 `host_permissions` 限制。
手工配置表单显示期间暂停自动轮询，输入或粘贴的课堂 ID 与教师令牌不会被周期刷新清空；连接成功后才恢复每 3 秒刷新。
扩展更新会使已打开页面中的旧内容脚本失效；旧脚本会停止轮询并提示刷新 POLYV 页面，不再产生未处理的 Promise 错误。

## 当前能力

- 读取受保护的教师快照。
- 显示课堂状态、疑问 Top 3、独立学生数和仍困惑人数。
- 执行开始讲解、结束讲解、关闭疑问和重新打开。
- 生成理解检测草稿、审核发布、结束检测并查看作答统计。
- 按确定性困惑指数排序疑问，优先显示最需要处理的问题。
- 每 3 秒刷新，连接失败不影响 POLYV 页面。
- Shadow DOM 样式隔离。

## 后续

- 拖动位置和侧边栏模式。
- DeepSeek 讲解建议。
- 悬浮球和面板标题栏均可拖动，位置限制在当前浏览器视口内，可避开开播、聊天等关键控件。
- 后端不可达时悬浮球变灰并提供重新连接入口；播放器切换全屏时助手会重新挂载到全屏容器。
- 后台网络桥接仅允许当前绑定课堂的教师快照、疑问状态和理解检测接口；其他路径或方法会在发送前被拒绝。
- 教师后台可通过限定本机来源、限定 API 地址并验证课堂 UUID 的配对脚本，一键写入短期会话令牌；关闭浏览器后仍自动失效。
