# QuestionPulse 真实环境升级实施状态

更新日期：2026-10-22

## 已实现并自动验收

- 学生、教师能力已在后端按不透明 Bearer Token 隔离，学生使用课堂码加入。
- 学生快照与教师快照已拆分；学生不能访问教师快照、完整报告和写控制接口。
- 课堂结束后，提问、反馈、检测作答、聚类操作均冻结，学生播放器由前端销毁。
- 已结束课堂不能重新打开；教师通过“创建下一堂课”继续授课。
- POLYV 页面悬浮助手使用 Manifest V3、Shadow DOM 和最小权限，只访问 QuestionPulse API；教师令牌使用浏览器会话存储，关闭浏览器后失效。内容脚本经后台 Service Worker 请求后端，避免受 POLYV 页面来源的 CORS 限制。
- DeepSeek 支持结构化聚类决策和检测题生成；输出经 Pydantic 校验，调用及决策写入审计表。
- DeepSeek 未配置、超时或输出非法时使用明确标识的本地算法，课堂不丢问题。
- 理解检测形成“AI 草稿 → 教师审核 → 定向发布 → 数据库评分 → 报告统计”的闭环。
- 困惑指数由参与学生比例、最近问题强度、等待压力、仍困惑比例和检测错误率确定性计算；教师页可展开查看每个分量，悬浮助手按分数排序。
- 教师报告已加入理解检测目标数、作答数、答对数和正确率。
- 教师报告包含事实统计、理解检测结果和由问题、讲解状态、拆分操作及检测生成组成的可追溯时间线。
- 数据库迁移已升级到 `20261022_0009`；前端类型检查和生产构建、扩展静态检查、后端 lint 与 23 项自动测试全部通过。
- 已在内置浏览器实际完成创建课堂、契约导入、讲解状态流转、检测草稿、审核发布、报告展示和课堂结束；结束后学生播放器消失、输入冻结，教师检测自动关闭。
- 2026-10-22 使用本机私有 POLYV 凭据完成真实只读同步：首次读取并接收 3 条官方问题，第二次读取同样 3 条且新增 0、去重 3，证明真实连接和幂等处理有效。

## 仍需真人在真实环境完成

这些步骤需要浏览器权限、真实直播状态或第三方密钥，不能由自动测试代替：

1. 在 Edge 的扩展管理页加载 `extension/`，绑定当前课堂并确认悬浮助手不遮挡 POLYV 关键按钮。
2. 用 Edge 学生窗口观看一次真实 POLYV 推流，完成提问、反馈、检测和课堂结束全流程；服务端真实问答同步与幂等性已经通过。
3. 在后端私有环境配置 `LLM_API_KEY` 后，用非敏感课堂问题验证一次 DeepSeek 实际返回和失败降级。
4. 真实流程连续通过两次，再进行三分钟答辩演练和录屏。
