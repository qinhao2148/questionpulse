## 最终验收场景

1. 两个学生用不同说法提问，教师端出现一个簇并显示 2 名独立学生。
2. 教师点“开始讲解”后学生看到状态；结束讲解后出现反馈入口。
3. 一名学生修改反馈，人数不增加；教师能看到仍困惑者数量。
4. 教师拆分一条误合并问题，两个簇的统计立即一致。
5. 结束课堂后报告列出高频、已处理、未闭环和反馈覆盖率。
6. 关闭 embedding 服务后走明确降级路径；恢复后不丢问题。
7. POLYV 权限失败时明确显示“未连接”，演示数据带标识，不伪装真实链路。
