# 17—21 小时阶段：故障恢复与响应式验收

## 可靠性能力

- `/health/live` 判断应用进程存活；`/health/ready` 实际执行数据库查询并返回数据库、问题处理管线状态。
- 课堂保存 `integration_error` 和 `degraded_at`，教师端明确展示接入降级，而不是把断连伪装成正常连接。
- 本地演练端点 `POST /sessions/{id}/integrations/polyv/drill` 只接受 `contract_test`，可切换 `degrade/recover`，不会访问 POLYV。
- 接入降级不阻断 QuestionPulse 本地提问、聚类、教师处理、反馈和报告闭环。
- `POST /sessions/{id}/questions/retry-pending` 批量重试待处理问题，返回尝试、恢复和剩余数量。

## 路演故障演练

1. 在教师端先执行“验证 POLYV 契约”。
2. 点击“模拟接入断连”，确认橙色降级面板出现。
3. 继续从学生端提交问题并推进教师状态，证明本地业务闭环仍可运行。
4. 点击“恢复接入状态”，确认错误信息清空并回到 `contract_verified`。
5. 若存在 Embedding 待处理问题，点击“全部重试”，确认恢复数量与剩余数量。

## 响应式范围

- 桌面宽度：教师四列指标、双列疑问簇、右侧详情。
- 平板宽度：学生、教师详情和报告改为单列，指标保留两列。
- 手机宽度：指标与疑问簇单列，顶部操作、可靠性面板、问题操作纵向排列，观看区域缩短并保留提问入口。
