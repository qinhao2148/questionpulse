# 明日人工验收清单

以下项目必须依赖真实浏览器、摄像头或保利威主播控制台，今晚已跳过，不影响代码检查结果。

## 1. Edge 直播播放

1. 在保利威网页开播端开始频道 `8655930` 的直播。
2. 使用 Edge 打开新课堂的学生端地址。
3. 确认页面只显示保利威播放器，不再出现课程大标题或雷达圆遮挡。
4. 若 Edge 阻止自动播放，点击播放器中央播放按钮。
5. 若首轮拉流失败，确认页面出现“重新连接直播”，点击后无需整页刷新即可恢复。

记录：浏览器版本、是否出现错误码、从开播到首帧所需秒数。

## 2. 直播状态切换

1. 主播未开播时，学生端应显示“等待主播开始直播”。
2. 主播开播后，学生端状态应变为“POLYV LIVE”。
3. 主播暂停或断流时，学生端应显示等待提示并保留重连能力。
4. 在 QuestionPulse 教师端结束课堂记录后，学生端必须销毁播放器并显示归档页，即使保利威仍在推流也不得继续展示画面。
5. 在保利威主播控制台点击“结束直播”，确认频道停止推流。

## 3. 新课堂流程

1. 在已结束课堂的教师端点击“创建下一堂课”。
2. 确认进入新的课堂 ID，状态为进行中，问题与报告从零开始。
3. 确认上一堂课的教师端保持只读，报告和问题统计不变。
4. 确认新课堂仍绑定配置的 POLYV 频道。

## 4. 权限边界

- QuestionPulse 的“结束课堂记录”只结束本系统的互动会话并关闭学生端播放器。
- 保利威的“结束直播”必须在主播控制台执行；两个动作属于不同系统，界面已经明确提示。
- 不在 QuestionPulse 前端保存或暴露 App Secret、推流密钥或主播登录令牌。
