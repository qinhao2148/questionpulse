# QuestionPulse 真实环境升级总方案

更新日期：2026-10-22

## 1. 升级目标

将当前适合本地演示的 V1 升级为符合真实直播课堂使用逻辑的产品：学生、教师和管理员拥有不同入口与权限；教师在 POLYV 网页开播台内使用 QuestionPulse 悬浮助手；DeepSeek 负责语义分析，数据库保证事实准确；任何 AI 建议均可追溯、可纠正、可降级。

比赛版本的核心体验应当是：

> 教师在熟悉的 POLYV 页面开播，不需要切换页面；QuestionPulse 悬浮助手实时识别群体疑问、给出讲解建议，并在讲解后通过理解反馈与即时检测验证学习效果。

## 2. 当前 V1 与真实环境差距

| 当前情况 | 真实环境要求 | 修改方向 |
| --- | --- | --- |
| 学生端、教师端和报告端共享导航 | 不同角色只能看到被授权入口 | 移除跨角色导航，增加独立入口和路由守卫 |
| 课堂 UUID 即可访问完整页面 | URL 不能代替身份认证 | 教师会话令牌、学生加入令牌和公开报告令牌 |
| 教师端直接显示所有原始问题 | 只有授权教师可查看 | 拆分学生快照和教师快照 |
| 教师需在 POLYV 与 QuestionPulse 间切换 | 教师应留在开播工作流 | Chromium 扩展悬浮助手 |
| 本地语义哈希是主要聚类 | 复杂语义需要模型理解 | DeepSeek 为主，本地算法降级 |
| 只有主观理解反馈 | 需要更客观的学习证据 | AI 生成、教师确认的即时检测题 |
| 报告只有单堂课事实统计 | 需要体现教学改进价值 | 困惑时间线、检测结果和 AI 教学建议 |
| 前后端本机 HTTP 运行 | 真实环境需要安全传输 | HTTPS、受控 CORS、反向代理和密钥管理 |
| 没有完整角色审计 | 教师写操作必须可追溯 | 认证主体、操作日志和 AI 决策审计 |

## 3. 真实角色和入口

### 学生

入口：

```text
/join/:classroomCode
/student/:sessionId
```

可以：

- 加入指定课堂；
- 观看绑定的 POLYV 直播；
- 提交自己的问题；
- 查看自己参与的疑问簇摘要和处理状态；
- 提交自己的理解反馈；
- 回答发给自己的即时检测题；
- 查看教师允许公开的课堂总结。

不可以：

- 查看其他学生原始问题或身份；
- 查看完整教师统计；
- 修改疑问簇状态；
- 同步 POLYV 数据；
- 结束课堂；
- 调用 DeepSeek 管理接口；
- 查看内部 AI Prompt、决策日志和完整报告。

### 教师

入口：

```text
/teacher/login
/teacher/classrooms
/teacher/:sessionId
```

以及安装后的 POLYV 页面 QuestionPulse 悬浮助手。

可以：

- 创建和管理自己的课堂；
- 绑定 POLYV 频道；
- 查看疑问簇和必要的原始问题；
- 确认 AI 聚类、合并和拆分建议；
- 开始讲解、结束讲解和关闭疑问；
- 审核并发送即时检测题；
- 结束 QuestionPulse 课堂记录；
- 查看完整报告与 AI 教学建议。

### 管理员

比赛版本可以暂不制作管理员 UI，但后端数据模型应预留：

- 管理教师账号和组织；
- 配置模型 Provider 和额度；
- 查看系统健康、失败任务和安全审计；
- 不默认查看学生问题正文。

### 演示员

仅在开发或比赛演示环境启用：

```text
/demo
```

用于创建演示课堂、查看三端地址和运行明确标注的合成数据。生产构建必须关闭或严格限制该入口。

## 4. 导航与页面调整

### 学生端

- 顶部只显示品牌、课堂课题和直播状态。
- 不显示教师端或完整报告入口。
- 只显示与当前学生有关的问题、反馈和检测题。
- 课堂结束后销毁播放器，显示经教师允许的总结入口。

### 教师端

- 顶部显示课堂列表、当前课堂、报告和账号菜单。
- 不提供伪装成学生的直接身份切换。
- 完整教师端用于配置、历史和详细处理；直播中主要使用悬浮助手。

### 报告端

- `/teacher/:sessionId/report`：教师完整报告。
- `/report/public/:shareToken`：可选的脱敏公开报告。
- 公开报告不显示学生身份、原始问题、内部错误或 AI 审计信息。

## 5. 身份认证与授权

### 比赛可实现方案

- 创建课堂时生成随机教师管理令牌。
- 学生使用短课堂码加入，后端签发当前课堂的学生会话令牌。
- Token 使用安全随机值或签名 JWT，设置课堂、角色和过期时间。
- 教师令牌只保存在扩展的 `chrome.storage.session` 或受控本地会话中。
- 令牌不放在分享 URL 查询参数、日志或截图中。

### 产品化方案

- 教师使用账号密码、企业 SSO 或 POLYV 身份授权登录。
- 学生身份由 POLYV viewer 身份、学校身份或匿名课堂会话映射。
- 使用短期访问令牌和可撤销刷新会话。
- 后端按组织、教师、课堂和角色执行资源级授权。

### API 权限

| API 类型 | 学生 | 教师 |
| --- | ---: | ---: |
| 学生快照 | 自己所在课堂 | 可选 |
| 提交问题 | 自己 | 可代测但需标记 |
| 提交反馈/答案 | 自己 | 否 |
| 教师快照 | 否 | 是 |
| 聚类状态修改 | 否 | 是 |
| POLYV 同步 | 否 | 是 |
| AI 分析与建议 | 否 | 是 |
| 结束课堂 | 否 | 是 |
| 完整报告 | 否 | 是 |

前端隐藏按钮只是体验处理，后端必须对每一个接口验证主体和角色。

## 6. API 拆分

现有统一 snapshot 应拆分：

```text
GET /sessions/{id}/student-snapshot
GET /sessions/{id}/teacher-snapshot
GET /sessions/{id}/public-summary
```

身份相关接口：

```text
POST /auth/teacher/login
POST /sessions/{id}/join
POST /auth/refresh
POST /auth/logout
GET  /auth/me
```

教师业务接口继续保留，但统一要求教师权限：

```text
POST  /sessions
POST  /sessions/{id}/integrations/polyv/sync
PATCH /sessions/{id}/clusters/{clusterId}/status
POST  /sessions/{id}/questions/{questionId}/detach
POST  /sessions/{id}/end
```

所有写接口记录操作者、时间、来源、旧值、新值和请求 ID。

## 7. 教师悬浮助手

### 形式

- Manifest V3 Chromium 扩展。
- 仅在允许的 POLYV 网页开播域名注入。
- 使用 Shadow DOM 隔离样式。
- Edge 和 Chrome 可加载同一份构建产物。
- 只访问 QuestionPulse 后端，不读取 POLYV 页面中的密钥或摄像头数据。

### 收起状态

- 52px 疑问脉搏球。
- 显示未处理疑问数量。
- 高优先级疑问触发一次脉冲。
- 断连变灰并显示可恢复状态。

### 展开状态

- 课堂连接状态；
- 当前讲解问题；
- 疑问 Top 3；
- 独立学生人数；
- 困惑预警；
- DeepSeek 摘要与讲解提纲；
- 开始讲解、结束讲解和关闭疑问按钮；
- 可跳转完整教师后台。

### 安全要求

- 最小化 `host_permissions`。
- 不申请摄像头、麦克风和浏览历史权限。
- 不读取或修改 POLYV 直播控制 DOM。
- 不自动点击开始直播或结束直播。
- 悬浮助手故障不得影响原开播页面。

## 8. DeepSeek 主要语义层

### 主要能力

- 问题意图规范化；
- 加入已有簇或创建新簇；
- 生成疑问标题和摘要；
- 给出置信度和理由；
- 发现可能的误合并和重复簇；
- 生成讲解提纲和即时检测题；
- 根据事实报告生成教学建议。

### 数据流程

```text
原始问题先入库并标记 pending
            ↓
3～5 秒微批收集
            ↓
构造脱敏、有限上下文
            ↓
DeepSeek 返回结构化 JSON
            ↓
Pydantic/JSON Schema 校验
            ↓
验证课堂、问题和疑问簇 ID
            ↓
事务写入聚类结果与 AI 审计
```

### 降级

- 超时、429、5xx、空响应、非法 JSON：保持 pending 并退避重试。
- 演示需即时显示时，使用本地语义哈希生成 fallback 聚类。
- fallback 结果明确标记，不伪装为 DeepSeek 结果。
- 已经由教师确认的聚类不被后续模型自动覆盖。
- DeepSeek 恢复后可重新分析低置信度与 fallback 结果。

## 9. 即时检测题

### 流程

1. 教师结束一次疑问讲解。
2. DeepSeek 根据疑问原文和教师确认知识点生成一道单选题草稿。
3. 教师检查题干、选项、答案和解析。
4. 教师确认发送给本轮目标学生。
5. 学生在规定时间内作答。
6. 数据库评分并计算正确率。
7. 悬浮助手展示理解反馈与客观正确率差异。

### 状态

```text
draft → approved → active → closed
  └──────── rejected
```

### 数据表

- `check_questions`
- `check_options`
- `check_targets`
- `check_responses`

模型生成题目草稿，不直接发送；评分、去重、目标学生和正确率全部由后端确定。

## 10. 疑问脉搏与预警

`confusion_score` 使用确定性数据计算：

- 独立提问学生比例；
- 最近一分钟问题增长率；
- 等待处理时长；
- 讲解后仍困惑比例；
- 即时检测错误率。

分数与权重在配置中固定并记录版本。DeepSeek 只将结果解释成一句教师易读的提醒，不生成分数。

## 11. 报告升级

报告分为两层：

### 事实统计

- 独立参与学生数；
- 问题数和疑问簇数；
- 每个疑问簇的影响人数；
- 处理状态和等待时间；
- 理解反馈覆盖率；
- 即时检测正确率；
- 再次讲解前后的变化；
- 疑问时间线。

### AI 建议

- 本堂课主要认知障碍；
- 需要复习的知识点；
- 建议的下节课顺序；
- 可使用的讲解例子。

报告必须在视觉上区分事实与 AI 建议，AI 建议引用对应疑问簇，不能生成数据库中不存在的统计数字。

## 12. 数据与隐私

- 原始 POLYV viewerId 经服务端单向映射后使用。
- 发给模型的是内部问题 ID和正文，不包含姓名、联系方式和原始 viewerId。
- App Secret、DeepSeek API Key、推流地址和登录令牌只保存在后端密钥环境。
- 日志默认记录请求 ID、状态码、耗时和错误类别，不记录完整 Token 或完整 Prompt。
- 提交包、海报、录屏和终端截图必须通过敏感信息检查。
- 生产环境需要数据保留期限和课堂删除机制；比赛版本先记录为产品化要求。

## 13. 课堂生命周期

```text
created → live → ended → archived
```

- `created`：课堂已创建但尚未开始互动。
- `live`：允许加入、提问、反馈和检测。
- `ended`：停止所有业务写入，学生播放器销毁，报告冻结。
- `archived`：长期保存或按策略删除。

结束 QuestionPulse 课堂不等于结束 POLYV 推流。悬浮助手应提示教师随后在 POLYV 开播台结束直播。

已结束课堂不可重新打开。继续授课创建新课堂，并可选择关联上一堂课作为续课。

## 14. 部署结构

比赛环境：

```text
Edge/Chrome 扩展 + Vue 学生端
             ↓ HTTPS/本机受控 HTTP
          FastAPI
        ↙         ↘
    MySQL       DeepSeek API
        ↘         ↙
          POLYV API/SDK
```

产品化环境增加：

- HTTPS 反向代理；
- 受控域名 CORS；
- 数据库备份；
- 后台任务队列；
- 限流和并发控制；
- 监控、告警和结构化日志；
- 多组织数据隔离；
- 密钥托管与轮换。

## 15. 测试与验收

### 权限

- 学生不能访问教师快照和完整报告。
- 修改 URL 不会获得其他角色权限。
- 过期、撤销、错误课堂 Token 均被拒绝。
- 教师只能管理自己有权限的课堂。

### AI

- 正常、超时、429、5xx、空输出、非法 JSON、截断输出。
- 模型返回不存在或跨课堂 ID。
- 同一批次重试不重复归簇。
- fallback 不覆盖教师确认结果。
- AI 结果可追溯到模型和输入指纹。

### 课堂

- 结束后所有写接口返回 409。
- 新课堂拥有独立问题、反馈和报告。
- QuestionPulse 结束后学生端不再加载播放器。
- POLYV 推流和本地课堂结束边界清楚。

### 扩展

- Edge 和 Chrome 均可加载。
- 页面刷新、路由切换和全屏后恢复。
- 不遮挡直播关键按钮。
- 后端断开时 POLYV 页面仍正常。
- 扩展包不包含任何密钥。

### 即时检测

- 只有目标学生可以作答。
- 每人每题只有一份最终答案。
- 教师未批准的草稿不能发送。
- 正确率完全由数据库答案计算。

## 16. 实施优先级

### 比赛前必须完成

1. 移除学生端跨角色导航。
2. 拆分学生和教师快照。
3. 增加最小教师令牌与学生课堂会话。
4. 完成教师悬浮助手基础版。
5. 完成 DeepSeek 主要聚类和本地降级。
6. 完成即时检测题最小闭环。
7. 完成困惑预警和三分钟演示流程。
8. 完成 Edge 真实直播、权限和降级验收。

### 比赛前有余力完成

1. AI 与本地算法评测面板。
2. 疑问时间线。
3. 公开脱敏报告。
4. 演示导演模式。
5. 视觉与动画打磨。

### 比赛后产品化

1. 正式教师账号、SSO 和组织权限。
2. 后台任务队列和水平扩展。
3. 多课堂趋势与学生复习卡。
4. 数据删除、导出和保留策略。
5. 扩展商店发布和集中部署。

## 17. 推荐开发顺序

```text
权限与角色边界
    ↓
悬浮助手基础版
    ↓
DeepSeek 主要聚类
    ↓
即时检测题
    ↓
困惑预警
    ↓
报告与时间线
    ↓
真实 Edge 验收和演示打磨
```

不能先做大量 AI 功能再补权限。学生和教师边界、原始数据安全以及课堂终态是后续所有功能的基础。

## 18. 功能冻结标准

满足以下条件后停止新增功能，只进行修复、录屏和答辩演练：

- 学生无法访问教师能力。
- 教师在 POLYV 页面内完成疑问处理。
- DeepSeek 聚类可解释且失败不丢问题。
- 即时检测题只能由教师确认后发送。
- 结束课堂后数据不可修改且播放器销毁。
- Edge 中真实直播完整流程连续通过两次。
- 三分钟演示连续通过两次。
- 提交包敏感扫描通过。
