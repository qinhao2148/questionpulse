# QuestionPulse 三分钟路演脚本

## 0:00—0:25 问题

在直播课堂中，学生的问题往往碎片化、重复并快速被淹没。保利威已经提供提问和问答能力，但当几十名学生使用不同表达提出相同困惑时，教师仍然需要逐条阅读，难以及时判断应该先讲什么。

## 0:25—0:45 方案

QuestionPulse 是构建在 POLYV 互动数据之上的群体疑问聚合与教学闭环系统。它不替代保利威提问功能，而是补充“聚类、优先级、反馈和追踪”这一层。

## 0:45—1:20 学生提问与聚类

演示两名学生分别提交“递归为什么需要结束条件”和“没有 base case 会发生什么”。系统保留两条原始问题，通过语义向量将它们归为同一疑问簇，并显示两名独立学生受到影响。重复请求不会重复计数。

## 1:20—1:50 教师处理

教师端按照影响人数排列疑问簇。教师点击“开始讲解”，学生端同步显示当前处理的问题。若模型把问题错误合并，教师可以拆分任意原始问题，系统同步修复统计和聚类质心。

## 1:50—2:20 理解反馈

讲解结束后，真正受到该问题影响的学生会收到“已理解／仍困惑”反馈入口。同一名学生可以修改本轮反馈但不会重复计数，教师能立即看到讲解是否解决了问题。

## 2:20—2:40 报告

课堂结束后生成可追溯报告，展示高频疑问、影响人数、反馈覆盖率和仍需跟进的问题，并支持打印和 CSV 导出。每个结论都可以追溯到原始问题。

## 2:40—3:00 稳定性与价值

模型异常时问题不会丢失，而是进入待处理队列；接入断连时本地课堂闭环继续工作。QuestionPulse 让教师从“逐条看问题”转向“发现群体困惑、优先讲解并验证理解”。

## 评委追问口径

- **保利威是否已有类似功能？** 保利威已有提问、问答和知识库 AI 答疑；公开资料中未发现“相似问题聚类—影响人数排序—讲解后反馈—课后追踪”的完整闭环。
- **是否真实接入？** 已完成真实观看页 SDK 播放与提问，并由服务端签名 API 读取一条官方问题；首轮导入成功，第二轮按官方 ID 去重，课堂状态显示 `live / connected`。本地种子数据仍明确标注为演示数据，不能把它说成真实用户数据。
- **为什么不直接让 AI 回答？** 本项目优先增强教师对群体学习状态的判断。自动回答可能掩盖误解，而教师讲解加学生反馈可以形成可验证闭环。
