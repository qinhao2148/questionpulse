# QuestionPulse 三分钟路演脚本

## 演示前固定画面

- Edge 左侧标签：POLYV 开播台，已安装 QuestionPulse Teacher Copilot。
- Edge 右侧窗口：QuestionPulse 学生端，已进入全新课堂。
- 教师悬浮球停在开播、聊天和结束直播按钮之外。
- 准备两个含义相同、表达不同的问题，以及一条不同主题的问题。
- 保留一份已完成课堂的报告作为网络异常时的备用展示。

## 0:00—0:25｜问题

“直播课堂不是没有问题，而是问题太多、太碎、太快。保利威已经提供直播和提问能力，但当几十名学生用不同表达描述同一个困惑时，教师仍要逐条阅读，也无法立刻知道一次讲解是否真的解决了问题。”

**画面动作：** 保持 POLYV 开播台，展开右下角 QuestionPulse 悬浮助手。

## 0:25—0:45｜方案

“QuestionPulse 是构建在 POLYV 直播和互动数据之上的课堂疑问雷达。教师不离开原来的开播页面，系统就能识别群体疑问、按影响人数和困惑程度排序，并在讲解后通过主观反馈和客观检测形成闭环。”

**画面动作：** 指向悬浮助手的连接状态、未处理数量和 Top 疑问。

## 0:45—1:15｜真实接入与语义聚类

“学生在自定义观看页观看 POLYV 直播并提问。问题通过官方 SDK 发送，服务端再使用官方签名 API 同步，保存官方 ID 并幂等去重。DeepSeek 会规范化问题意图，判断加入已有疑问簇还是创建新簇；模型超时或异常时，本地语义算法会立即接管，问题不会丢失。”

**画面动作：** 两名学生依次提交“递归为什么需要结束条件”和“没有 base case 为什么会栈溢出”，教师点击同步，展示它们进入同一疑问簇；指出来源标记和 AI 语义依据。

## 1:15—1:50｜教师悬浮助手与困惑预警

“教师仍停留在 POLYV 开播台。悬浮助手按独立提问人数、最近问题增长、等待时长、仍困惑比例和检测错误率计算确定性的困惑指数。DeepSeek 负责解释语义，人数、状态和分数始终由数据库计算，AI 不会编造统计。”

**画面动作：** 在悬浮助手点击“开始讲解”，讲解十秒后点击“结束讲解”；展示学生端同步出现理解反馈。

## 1:50—2:25｜理解反馈与即时检测

“只问‘听懂了吗’容易产生虚假的理解感。因此 QuestionPulse 会让 DeepSeek 生成一道单选题草稿，必须由教师审核后才能定向发送给本轮相关学生。答案、目标名单、一次性作答和正确率都由后端控制。”

**画面动作：** 点击“生成检测草稿”和“审核并发布”；学生作答；悬浮助手刷新为 `1/1 已答 · 1 人正确`，再结束检测和关闭疑问。

## 2:25—2:48｜报告与可追溯性

“课后报告区分数据库事实和 AI 教学线索：问题数、影响人数、反馈覆盖率、检测正确率和时间线都能追溯到原始记录；DeepSeek 的模型、输入指纹、耗时和决策理由也保留审计。”

**画面动作：** 打开教师报告，快速展示事实统计、理解检测、AI 教学线索和课堂时间线。

## 2:48—3:00｜价值

“QuestionPulse 不替代教师，也不重复直播平台已有能力。它把分散的提问变成可排序的群体困惑，把一次讲解变成可验证的学习闭环，让教师在直播进行时就知道先讲什么、谁还没懂，以及下一步应该怎么教。”

## 网络异常备用口径

- **POLYV 问答暂不可用：** 页面明确显示降级，问题先安全写入 QuestionPulse，恢复后继续同步。
- **DeepSeek 暂不可用：** 本地语义算法生成带 `fallback` 标记的结果，不伪装为模型输出。
- **现场推流异常：** 使用已完成课堂报告展示真实官方问题 ID、处理时间线和检测记录，不把演示数据描述为实时数据。

## 评委追问口径

- **保利威是否已有类似功能？** 保利威已有直播、提问、问答和知识库 AI 能力。QuestionPulse 增加的是“相似问题聚类—群体困惑排序—教师讲解—理解反馈—即时检测—课后追踪”的教学闭环。
- **是否真实接入？** 已在频道 `8655930` 完成官方观看 SDK、真实提问、服务端签名 API 同步、官方 ID 去重和 DeepSeek 聚类；课堂状态为 `live / connected`。可见 Edge 的视频首帧仍按现场清单复核，不能用播放器占位冒充画面证据。
- **为什么不让 AI 直接回答？** 项目要解决的是教师无法掌握群体学习状态的问题。AI 负责语义理解和出题草稿，教师保留教学决策，数据库负责事实和评分。
- **AI 判断错了怎么办？** 教师可以拆分问题、改变处理状态并审核检测题；模型失败时使用明确标记的本地降级，后续可重新分析低置信度结果。
- **隐私如何处理？** POLYV viewerId 在服务端单向假名化；模型上下文不包含姓名、联系方式、密钥或原始 viewerId；教师令牌只保存在浏览器会话中。
