## 已确认的核心信息

- 校园赛道面向校企合作在校学生。
- 课题方向为使用 POLYV API 或 SDK 开发小工具、小程序或 App。
- 支持单人或团队参赛，团队原则上不超过 3 人。
- 第一阶段按创新力、技术实现力、体验与设计力、实际价值、展示与感染力五项评分，每项 20%。
- 海报时间线标注 10 月 23—24 日为 24 小时线下创作。

报名、提交格式、赛前代码是否允许带入等细节，应以主办方的最新通知为准。
